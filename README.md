# 赵佳佳的博客：以后怎么修改

这是静态博客，没有文章管理后台。文章内容集中放在 `content.js`，首页和文章列表都会自动读取它，所以平时写文章不需要改 HTML。

## 每个文件管什么

| 文件 | 修改内容 |
| --- | --- |
| content.js | 作者介绍、文章标题、分类、日期、摘要和完整正文 |
| style.css | 配色、字体、布局、卡片等样式 |
| app.js | 页面结构、筛选、搜索、作品链接等交互；目前部分固定介绍文字也在这里 |
| index.html | 网页标题、搜索引擎简介、导航和资源入口 |

## 最简单：直接在 GitHub 上编辑文章

1. 打开 [博客仓库的 content.js](https://github.com/KuailEzjj/KuailEzjj.github.io/blob/main/content.js)。
2. 点击文件右上角的铅笔图标（Edit this file）。
3. 找到要改的文章，修改文字。保留文字外面的双引号、方括号和逗号。
4. 点击 **Commit changes**，填写例如“更新学习笔记”，确认提交到 main。
5. 等 GitHub Pages 发布完成，再刷新博客。如果还是旧内容，按 Ctrl + F5。

已经开启 Pages，无需每次重新设置。提交会更新公开网站，因此写完先检查有没有不适合公开的内容。

## 一篇文章怎么填

```js
{
  "id": "my-new-note",
  "title": "我的新文章标题",
  "date": "2026-10-26",
  "category": "学习",
  "summary": "一句话介绍文章，显示在首页和文章列表。",
  "body": [
    ["p", "第一段正文。"],
    ["h2", "一个小标题"],
    ["p", "小标题下面的正文。"]
  ]
}
```

- 新增文章：在 posts 的方括号中复制一整篇，各篇之间用英文逗号分隔。不要把它放在 posts 外面。
- id：每篇唯一，用英文、数字或连字符。旧文章尽量不改 id，原阅读链接会继续有效。
- date：使用 YYYY-MM-DD；首页自动按日期从新到旧显示最近三篇，同一天保留文件里的顺序。
- category：填写“随笔”“学习”或“生活”，分类按钮会自动出现，不用手动改筛选栏。
- summary：列表卡片上的简介。body：点击进入后看到的完整文章。
- body 目前支持 p 正文和 h2 小标题。内容按纯文字显示，不解析 Markdown 或 HTML。
- 文字里要用双引号时，建议改用中文引号“”，避免破坏 JavaScript 字符串。

## 在电脑上改也可以

打开本地 `content.js` 编辑，再预览 `index.html`。也可以在本文件夹运行 `python -m http.server 4173`，浏览器打开 http://127.0.0.1:4173。

本地保存只影响本地预览；要让大家看到，需要把修改后的文件提交或上传到同一个 GitHub 博客仓库。不要额外套一层文件夹。

当前 content.js 中是三篇围绕五金立体库开发整理的文章。它们的旧 id 保留，因此已有阅读链接不变。生活篇是开发与日常节奏的感想，没有添加旅行、家庭或具体私人日程等未经提供的经历。
